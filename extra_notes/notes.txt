imPROVING recommendation late on:
Here's the mechanism, plainly:

**Right now**, a search does this: turn the typed vibe into a vector → compare to every place's vector → rank by closeness.

**Using feedback** works the same way, just swapping *what* gets turned into a vector:

1. Every place the user has liked/saved already has an embedding (you computed it once when seeding).
2. Average those liked places' vectors together → that average is a single vector representing "what this user tends to like."
3. Compare *that* vector to every place's vector, same as a normal search — rank by closeness.

So a "based on your history" search isn't a different algorithm — it's the exact same comparison step, just fed a vector built from past likes instead of typed text. That's why we built it as a query-vector-vs-place-vectors comparison from the start: whichever vector goes in (typed text or liked-places average), the ranking logic doesn't change.

**Weighting, if you want it smarter later:** instead of a plain average, weight more recent likes higher, or weight a "save" more than a "click." But the plain average is a real, working version to start with.

One concrete effect this has on your toggle: right now you have "vibe search" vs. "least known first." This adds a third mode — "based on what you've liked" — using the same underlying comparison, just a different input vector.

Want to build this now (step 3, after embeddings exist), or finish plain vibe-search first and add history-mode after?

Here's the whole thing, no code, just the logic:

You already have embeddings for your 10 hardcoded places — each one's name+description turned into 384 numbers representing its meaning.
Turn the typed query into the same kind of numbers — same embedding model, applied to the search text instead of a place description.
Compare the query's numbers to every place's numbers — pgvector's <=> operator measures how close two sets of numbers are. Smaller distance = more similar meaning.
Sort by that distance, closest first — that's your ranked, vibe-matched result list.
